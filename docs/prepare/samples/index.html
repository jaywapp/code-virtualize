최종 화면과 frontend 기술은 아직 선택하지 않았습니다.

모든 값은 합성 예제입니다. 실제 저장소, 분석 엔진, 서버, Git에 연결하지 않습니다. 검색·심볼 선택·원문/주석·baseline 전환·상태 복구·테마 전환을 직접 조작할 수 있습니다. 표시된 참조가 전체 의존성이나 영향 범위를 증명하지 않습니다.
